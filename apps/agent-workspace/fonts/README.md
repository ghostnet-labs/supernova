# Font sources

MonaSansVF.ttf is the unmodified variable font from github/mona-sans,
`fonts/variable/MonaSansVF[opsz,wght].ttf`, retrieved October 21, 2026.
Git blob SHA: `386181a376918b4e211402634b051aaf9ca65724`.
Its SIL Open Font License is in OFL.txt and is bundled with the app.

OpenAI Sans and Anthropic Sans/Serif are loaded locally from the installed
ChatGPT and Claude applications. They are not redistributed in this repository.
